# Claude Knowledge Notes

Reference notes so any Claude session, on any computer, starts with beyondGREEN business context.

## How to use
- Before starting work, read working-rules.md plus the file(s) relevant to the task.
- After each task, add a dated note to `docs/claude-notes/` (e.g., `2026-11-01-topic.md`) and update the relevant file here if something durable was learned.
- This repo may be seen by the team and developers: never add personal details, legal matters, investor or financial figures, pricing/costs/margins, contact emails or phone numbers, or secrets/IDs.

## Files
- working-rules.md: Rudy's standing preferences (writing, delivery format, Walmart terms, die line format).
- company.md: what beyondGREEN makes, entities, facilities, certifications, customers, claims rules.
- products-and-engineering.md: product lines, resins, manufacturing methods, lead times, projects in development.
- walmart-program.md: Great Value program, weekly reporting, Stride/shipping method, SRP dims, compliance.
- sales-outreach.md: outreach rules, Apollo/Outlook process, California phases, big-org approach.
- sourcing.md: packaging supplies and PLA from China, imports, Epsilon Pacific.
- websites-and-ecommerce.md: byndgrn.com, new site build rules, Amazon, WildKind.
- command-center-and-jarvis.md: Command Center and Spica requirements, old Jarvis history.
- marketing-rules.md: claims language, positioning, channel rules.
- programs-and-incentives.md: incentive programs, LACI, LCA, certifications in progress, trade shows, bG-Pro portal.
- claude-setup-and-roadmap.md: approved connectors, skills, Claude Code add-ons, pending ERP builds, to-dos.
