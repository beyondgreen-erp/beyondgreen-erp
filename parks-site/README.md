# Pet Waste Bag Program

Standalone public landing page for beyondGREEN's municipal / HOA pet-waste-bag outreach.
Deployed as its own Vercel project so the URL does not expose the ERP domain.

## Vercel setup
- Project name: pet-waste-bag-program
- Root Directory: parks-site
- Framework preset: Next.js
- Env vars: NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY
